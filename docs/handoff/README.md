## Что это за продукт

**e-comgen / eg_ai_features** — AI-SaaS, который автозаполняет структурированные
атрибуты карточек товаров для российских маркетплейсов (Ozon, WB, в перспективе
Я.Маркет). Вход: товар (название, описание, бренд, штрихкод, категория) + схема
целевых атрибутов маркетплейса. Выход: заполненные атрибуты с `value_id`
словарей, готовые к импорту.

Бизнес-принцип №1: **«пусто честнее мусора»** — лучше оставить атрибут пустым
(`no_data`), чем заполнить выдуманным/неверным значением. Ozon отвергает неверные
словарные значения при импорте, а неверный филл подрывает доверие клиента.

## Архитектура из 3 сервисов

1. **PHP-аддон CS-Cart** (`eg_ai_features`) — коннектор в админке CS-Cart, точка
   входа для пользователя. Лежит в отдельном репо/проекте
   (`C:\MAMP\htdocs\multivendor\app\addons\eg_ai_features`).
2. **ai_orchestrator** (порт **:8000**) — биллинг, оркестрация, файл-анализ
   (`/manage/update/inspect`). Отдельный сервис/репо.
3. **cpAiFeatures** (ЭТОТ репо) — **LLM-движок обогащения**. Принимает batch
   товаров + схемы, гоняет cost-aware пайплайн, возвращает контракт v2. Воркер
   поднимается на порту **:8002**.

**eg_importer** — ОТДЕЛЬНЫЙ сервис (не в этом репо). Потребляет выход движка,
строит xlsx-шаблоны Ozon, управляет запуском/рестартом воркера :8002. Когда в
задачах фигурирует «eg_importer поднимал воркер» — речь про него.

Подробнее монетизация: pay-per-use, баланс/пополнение через LavaTop, списание за
запрос; CS-Cart аддон как коннектор.
