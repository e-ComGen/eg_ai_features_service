# Журнал ключевых фиксов и решений

Тематически, с коммитами. Это «почему так сделано», чтобы не переоткрывать
болезненно решённое.

## ТН ВЭД (сага резолва таможенного кода ЕАЭС)

Словарный атрибут Ozon. При импорте требует ТОЧНЫЙ полный ярлык словаря категории
+ `value_id`, а не голый код. Эволюция:

- `aee4155`/`1e35444`/`6a4b2d9` — отбрасывать заголовки групп, валидировать против
  справочника Ozon (`list_values`), отдавать ПОЛНЫЙ ярлык, не голый код.
- `dbee3b5` — подкод через **constrained-pick**: LLM выбирает из реальных ярлыков
  категории (183 кода у кроссовок), prompt «предпочитай специфичную
  подкатегорию». Слепой guess давал валидный, но семантически неверный подкод.
- `9097881` — НЕ перетирать живой `value_id` (от `search_value`) статическим
  словарём (~50 sample-кодов/категория, сталые id коллапсировали на разные коды).
  Оба `resolve_value_ids`/`_async` пропускают значения с evidence-сентинелом
  `tnved_resolver:`.
- `626f562` — кэш ТН ВЭД по `(category_id, type_id)`, чтобы каждый тип одежды
  получал свой код.
- **Баг 4 (23.06):** депрекейтнутые записи словаря. `9acd4e1` — детектор
  `_is_deprecated_dict_label` (regex «Действие прекращено/приостановлено»,
  «утратил силу», «исключён») отсеивает снятые ярлыки ДО constrained-pick.
  `ab24ed7` (переоткрытие) — у снятой и ДЕЙСТВУЮЩЕЙ записи ОДИН код, разные
  value_id; брать value_id действующего брата (`_first_active_with_code`), а не
  ронять в no_data. Abstain только если действующей записи нет вовсе.

## Цвет — per-SKU вариантная ось (РЕШЕНО)

Цвет различает SKU (в отличие от состава/материала, которые product-invariant).
Донор по имени даёт ПАЛИТРУ чужой расцветки → мусор.

- `1c98573` — ловить строковую палитру (WB/marketplace join-ят мульти через `;`),
  дроп ДО merge.
- `5f6e294` — **надёжный источник цвета = НАЗВАНИЕ**: `_apply_color_from_name`
  стем-матчит токены имени против allowed_values (черные↔чёрный, ё→е).
- `d5cc451`→`2498b30`→`38b2007` — `_apply_color_source_guard` ALLOWLIST = только
  `Source.DESCRIPTION`; web_search/ozon_card/wb_card/vision/llm/rag — дроп.
  `_apply_ozon_api_resolve` пропускает color-таргеты. Принцип: цвет знают только
  имя/описание, гадать колорвей нельзя. Живой :8002: «…чёрные»→чёрный, без цвета
  в имени → no_data.

## Бренд

- `7fc3ae4` — заполнять free-text «Бренд» из названия через LLM, когда у
  категории нет brand-enum.
- `4e6fee0`/`d9a34ab` — full-dict needle lookup для apparel/коротких enum-брендов
  + category-noun guard; фоллбэк при усечённом срезе опций без бренда.
- `497485b` (**Баг 3**) — бэкфилл `context.brand` из имени на Stage 0d, когда
  продавец оставил колонку «Бренд» пустой. Пустой `context.brand` глушил
  brand-gated источники (ozon_card/regard/IceCat) → каскад no_data по Пол/Цвет/
  Размер. Высокоточно: ровно один словарный бренд из имени, иначе пусто.

## Enum-словари без `options` + устаревший category_id

- **Тостер (b1d7d6e):** «Количество отделений» — закрытый словарь {1,2,3,4}, но
  eg_importer не слал `options` для числовых словарей → verbatim «8» из описания
  протекало; IceCat мапил «уровней поджаривания=8». Фикс: (A) Stage 0c.5
  `_backfill_allowed_values_from_api` сам тянет `list_values`; (B)
  `resolve_description_category_id` — category_id из шаблона eg_importer БЫВАЕТ
  УСТАРЕВШИМ (тостер 47156221→17039630, наушники 17034949→17028929), правильный =
  родитель type_id в ЖИВОМ дереве Ozon, кэш на процесс; (C) enum-membership гард
  на финализе для не-LLM источников.
- **Наушники** — тот же класс (Гарантия=«Да», Регулятор громкости=«Кнопка»,
  Шумоподавление=«Встроенный»). Закрыт тем же b1d7d6e + рестарт воркера.
- **Многозначные (Ⓜ️) поля (b87a171, ПОСЛЕДНИЙ коммит):** «Функциональные
  особенности» — Множественный выбор, гард b1d7d6e ИСКЛЮЧАЛ списки → мусор
  («выдвижной лоток для крошек») тёк. Фикс: `_apply_enum_membership_guard`
  фильтрует каждый член списка через `_match_collection_member`
  (**token_set_ratio≥80**, НЕ WRatio — WRatio раздувается на общем хвосте
  «…тостов», пропускал «подогрев готовых тостов»=86 и ронял легит
  «автоцентрирование тостов»=81). Скалярный путь не тронут.

## Mud-гейты (анти-галлюцинация)

- `d0a6538`/`a24cbc4`/`cc30a2f` — llm_knowledge льёт галлюцинации в `filled`
  (Бязь, ABS-пластик conf 0.0). Фикс: adversarial Gate B (дефолт RETRACT),
  hard-drop `conf=0.0`, заглушка vision-material-лика; затем замена LLM Gate B на
  ДЕТЕРМИНИРОВАННУЮ source-corroboration для spec-class атрибутов.
- mud-гейт прикрывает ТОЛЬКО `safe_enum_fill`; llm_knowledge+vision гейтятся
  отдельно. «2.0» = собственные данные Ozon (серая зона, не наш mud).

## Что НЕ заполняем (by design, не баг)

Per-SKU поля, невыводимые из названия: российский размер обуви/одежды, «Объединить
в похожие», цвет без цвета в имени. Пусто честнее.
