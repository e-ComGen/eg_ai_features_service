# ADR: Recall-регресс web-fetch после Scrappey→scrape.do — пак из 3 гардов

Дата: 2026-07-05. Статус: ACCEPTED (Fable 5). Затрагивает: enrichment pipeline
(`ozon_card_source`, `wb_card_source`, `donor_gate`, `scrapedo_client`).

## Проблема

`coverage_optional_honest` (доля ЧЕСТНО заполненных optional-полей) просела с baseline
~76% (замер `eval_40cat.txt`, Jun16, ещё на Scrappey) до ~53% (Jul5, после миграции
транспорта Scrappey→scrape.do, FIX-10..17). Гипотеза «это блок-детектор dns/citilink»
оказалась ложной — Ozon/WB ходят через scrape.do так же, как Яндекс.Маркет/Lamoda.
Форензика показала: регресс — это НЕ один баг, а **кумулятивная recall-цена набора
анти-галлюцинационных гардов**, которые при миграции транспорта стали over-fire'ить на
валидном контенте. Часть падения ЧЕСТНАЯ (гарды правильно убили галлюны) + data-gaps
(товара нет на площадке); часть — регресс, подлежащий лечению.

## Ключевой факт, определивший решение (проверено чтением исходников)

Штрафы/абстейны корректны по НАПРАВЛЕНИЮ (галлюн лучше не заполнить, чем заполнить
чужим), но три из них срабатывали на ЛЕГИТИМНОМ контенте:
- Ozon type-matcher `_category_present_in_title`: фильтр токенов `len>=4` + префикс-правило
  `>=4` роняли короткие русские корни (сок/нож/еда/посуда) → ложный `-30 _TYPE_MISMATCH_PENALTY`
  → легит-победитель уходил в abstain на ЦЕЛЫХ категориях.
- WB donor-gate `is_same_product`: bool fail-open, при сбое транспорта/парса возвращал
  True И КЭШИРОВАЛ его — транзиентная ошибка замерзала как «тот же товар»; а на честном
  `different` дропал ВЕСЬ донор (`return []`), теряя все скачанные карты.
- WB candidate cap: брал top-10 в POPULAR-порядке ответа, не по релевантности — точный
  артикул мог быть за пределами top-10, оставался невыбранным.

## Решение: пак из 3 детерминированных/полу-детерминированных гардов, приоритет по recall/risk

- **#1 (шаг 1.1) Ozon matcher** — заменить `len>=4`/префикс`>=4` на стем-правило с
  `_RU_INFLECTIONS` (порог токена `>=3`, суффикс-инфлексия ≤2 символа из белого списка
  окончаний). Чистая функция, unit-доказуемо, 0 LLM. Оракул-тест `test_category_matcher_oracle.py`.
- **#3 WB re-rank** — собрать до 50 products из ТОГО ЖЕ ответа (0 доп. запросов/кредитов),
  локально отскорить title тем же fuzzy vs query, взять top-`_MAX_CANDIDATES`(=10, НЕ поднимать)
  ПО РЕЛЕВАНТНОСТИ, tie-break = popular-порядок. Чистый recall при нулевом precision-риске.
- **#2 WB donor-gate** — трёхзначный вердикт + budget re-pick (детали в отдельном ADR
  `ADR-2026-07-05-wb-donor-gate-three-valued-repick.md`).
- **#1 (шаг 1.2) LLM-эскалация** — на `score_wo_type` (score + penalty) звать существующий
  мемоизированный `_get_identity_verdict` (FIX-16): same→принять с классом `score_wo_type`;
  different/unknown→abstain. **ОТЛОЖЕНО** — вторая очередь, только если замер остатка покажет
  разрыв; возможно не понадобится.

Приоритет (по recall-выигрышу / precision-риску / стоимости): **#1.1 → #3 → #2 → #1.2**.

## Отвергнутые альтернативы

- **Downgrade-confidence → merge**: confidence в `_merge_winner` не участвует, карта prio 4
  всё равно победит. Не решает.
- **Эмит подозрительной карты как prio-2-источник**: ломает provenance, перебивает LLM-поля.
- **Per-field salvage у different-донора**: identity — свойство карты целиком; поля чужой
  карты = галлюн-класс.
- **Поднять `_MAX_CANDIDATES` до 30 с фетчем всех**: ×3 кредитов scrape.do + латентность;
  re-rank даёт то же бесплатно.
- **Выпилить/ослабить штрафы порогом**: возвращает класс галлюнов (M8→M8 Pro), запрещено
  constraints.

## Безопасность / что НЕ трогаем

- Направление гардов НЕ ослабляем: галлюн лучше не заполнить. Все фиксы — про то, чтобы
  гард не бил по ЛЕГИТу, а не про то, чтобы пропускать галлюны.
- Не трогаем живой :8002/:8003, не рестартим gateway 18789/18790.
- `_MAX_CANDIDATES=10` НЕ поднимать (кредиты/латентность).

## Риски и митигации

**Sentinel-suite precision (БЛОКИРУЮЩИЙ)** — зафиксированный набор галлюн-кейсов, которые
ОБЯЗАНЫ остаться abstain/drop: POCO X6→M8 Pro, X6→X6 Pro, S24→S23, iPhone 15→14,
«чехол для X6», Mi Band 8→карточка Mi Band 7 (WB donor), куртка↔шорты. Unit (моки) +
живой смоук по образцу Acceptance FIX-15/16. **Любой sentinel прошёл в мердж = FAIL всего
трека.** Митигация: оракул-тесты на каждый гард (`test_category_matcher_oracle.py`,
`test_wb_candidate_rerank.py`, `test_wb_donor_gate_repick.py`).

## План (диспетчеризация)

Код — tier-0 (deepseek) по verbatim-спеку, приземляет Opus-контроллер; Opus review на
Cyrillic-регрессы регекспов. Замер — `scripts/eval_multi_category.py` (40 категорий, дефолт-
конфиг = baseline 76.6%). Коммиты: #1 `af6db2b`, #3 `72be69b`, #2 `a333409`.

## Результат замера (2026-07-06, все 40 категорий, RAG живой)

`coverage_optional_honest = 66.5%`, `coverage_required = 92.2%`, `value_id 100%`. Источники:
ozon_card 356, llm_knowledge 310, wb_card 174, web_search 119, description 62, icecat 49,
competitor_rag 41, vision 36, safe_enum_fill 14. Для сравнения: donor-gate ON наивный (до #2)
= 46.9%; мой стек с МЁРТВЫМ RAG = 62.7% (RAG-пакет `qdrant_client` не был установлен — env-
регресс, чинён `pip install qdrant-client==1.18.0` + вписан в requirements). «76.6-baseline»
НЕсравним (в нём OzonCard был ВЫКЛ, нет SCRAPPEY_KEY).

## #1.2 (LLM-эскалация на -30 penalty) — ЗАКРЫТА как НЕ-нужная (по замеру)

Прямой DEBUG-замер: Ozon `-30` type-penalty систематических абстейнов НЕ даёт (Платье tile
score 71.3 = принята; все одёжные #21-28 имеют здоровый fill 16-23 honest; единственный
сильно-штрафованный тайл — Духи −14 — genuinely чужой gender+type, отвергнут ВЕРНО). 6
«честный 0» — все WB и все ЧЕСТНЫЕ (WB реально нет карты типа: веб-камера/тушь/мягкая
игрушка/куртка/умная колонка/гитара) — это не цель #1.2. Остаток разрыва — ИНФРА прогона
(27× scrape.do `502 ROTATION_FAILED` + 18× vision `image 404` на мёртвых wbbasket-картинках),
т.е. 66.5% сам по себе ПОЛ. #1.2 добавила бы LLM-стоимость за ~ноль recall → не реализуем.

## Допущения (проверить менеджеру)

- Регресс залечен настолько, насколько был регрессом; дальше — инфра (scrape.do capacity,
  WB image 404) + честные data-gaps, а не дефект гардов. Метрика — доля ВЕРНЫХ, не raw-fill.
