# MANIFEST — FIX-12: type-mismatch штраф не бьёт по правильному товару (HARDEN)

## Проблема (rooted 2026-07-02, диагностика скоринга)
`OzonCardSource._pick_best_match` отвергает РЕАЛЬНЫЕ карточки: Bosch GSB 13 RE = 57.1, POCO X6 5G =
28.8 при пороге `_BRAND_LINE_THRESHOLD = 65`. Порог НЕ виноват. Виноват штраф
`_TYPE_MISMATCH_PENALTY = 30` (строка ~1792), который ложно срабатывает на электронике:

```python
if cat_leaf_low and not q_models and cat_leaf_low not in title.lower():
    score -= _TYPE_MISMATCH_PENALTY
```

Два звена ломают его:
1. `not q_models`: `_extract_model_tokens` (стр 610) требует **len ≥ 3**, поэтому короткие модель-токены
   `X6`, `5G`, `13`, `RE` выбрасываются → `q_models` пусто → телефон/дрель считается «одеждой без
   артикула» → штраф разрешён.
2. `cat_leaf_low not in title.lower()`: `category_leaf` = таксономия CS-Cart, мн.ч./составное
   («Смартфоны», «Дрели ударные»), а в плитке Ozon — «Смартфон POCO…», «Дрель ударная Bosch…».
   Буквальной подстроки «смартфоны» в «смартфон poco…» НЕТ → условие истинно → **−30 срабатывает**.

Итог: Bosch (это был бы EXACT >78) 87 − 30 = 57; POCO 59 − 30 = 29. Оба ниже 65 → карта возвращает [].

## Цель
Штраф −30 должен срабатывать ТОЛЬКО при настоящем несовпадении типа (одежда: «Куртка» vs «Шорты»), а
не когда категория присутствует в другой словоформе. Порог, гарды бренда/гендера, бонусы — НЕ трогать.

## INV-12 (что чинить — ОДНА точка, стр ~1792)
Ввести stem/prefix-aware проверку присутствия категории и гейтить штраф по ней:

`_category_present_in_title(cat_leaf_low: str, title_low: str) -> bool`:
- токенизировать `cat_leaf_low` и `title_low` по `[\s\-–—/]+`, брать токены длиной ≥ 4 (кир/лат);
- категория СЧИТАЕТСЯ ПРИСУТСТВУЮЩЕЙ, если ХОТЬ ОДИН токен категории делит общий **префикс ≥ 4
  символа** с каким-либо токеном title (смартфоны↔смартфон, дрели↔дрель, куртки↔куртка);
- чистая функция, без I/O, без внешних зависимостей (голый `re`/срезы строк).

Изменить условие штрафа на:
```python
if (cat_leaf_low and not q_models
        and not _category_present_in_title(cat_leaf_low, title.lower())):
    score -= _TYPE_MISMATCH_PENALTY
```
Больше НИЧЕГО в `_pick_best_match` не менять. `_extract_model_tokens` НЕ трогать (не расширять на
короткие/чисто-цифровые токены — «44» это размер одежды, не модель; расширение сломало бы clothing-гард).
