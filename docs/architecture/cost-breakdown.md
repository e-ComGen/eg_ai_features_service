# Сколько это стоит

Этот документ — про деньги. Сколько обращений к ИИ и сколько денег уходит на обработку одного товара. Считаем для разных сценариев.

⚠️ **Этот документ обновлён** после исследования альтернативных провайдеров (май 2026). Подробная стратегия оптимизации — в [optimization-strategy.md](optimization-strategy.md).

---

## Базовая идея — два стека провайдеров

После исследования выбираем **дешёвый стек по умолчанию** + **премиум стек для критичных stages**:

**Дешёвый стек (применяется везде где возможно):**

| Задача | Провайдер | Цена /1M (in/out) |
|---|---|---|
| Основная extraction, classifier, knowledge, judges | **DeepSeek V3** (api.deepseek.com) | $0.14 / $0.28 |
| Vision (анализ фото) | **Gemini 2.5 Flash** | $0.30 / $2.50 |
| Web search | **Serper API** | ~$0.001 за запрос |

**Премиум стек (escalate только для сложных товаров через cascade routing):**

| Задача | Провайдер | Цена /1M (in/out) |
|---|---|---|
| Сложный reasoning | **Claude Sonnet 4.6** + prompt caching | $0.30 (cached) / $15 |
| Vision для нишевых | **GPT-4o Vision** | $2.50 / $10 |

Cascade принцип: ~70% товаров обрабатываются полностью на дешёвом стеке. ~30% сложных эскалируются к premium только тогда когда confidence от cheap-stack низкая.

## С учётом cascade routing на premium (Claude Sonnet 4.6 для 30% сложных)

В среднем mix: 70% дёшево, 30% premium escalation.

**Cost для premium-эскалации на одном товаре** (типичный сценарий):
- Базовый DeepSeek + Gemini обработал, но confidence low → escalate
- Дополнительные calls на Claude Sonnet 4.6: ~3-5 calls × $0.005-0.01 = $0.015-0.05
- **Итого с premium**: $0.02-0.06 на сложный товар (vs $0.0068 на простой)

Средневзвешенный cost: 0.7 × $0.0042 + 0.3 × $0.030 = **$0.012/товар (1.2 ₽)** в типичной нагрузке.

## Финальная экономика тарифов

| Пакет | Цена клиенту | Cost (твоё) | Чистая маржа | Маржа % |
|---|---|---|---|---|
| Trial 3 карточки | 0 ₽ | ~4 ₽ | -4 ₽ (привлечение) | — |
| Старт 200 карточек | 990 ₽ | ~240 ₽ + LavaTop 49₽ = 289 ₽ | **+701 ₽** | **71%** |
| Бизнес 1 000 карточек | 2 990 ₽ | ~1 200 ₽ + LavaTop 149₽ = 1 349 ₽ | **+1 641 ₽** | **55%** |
| Pro 5 000 карточек | 9 900 ₽ | ~6 000 ₽ + LavaTop 495₽ = 6 495 ₽ | **+3 405 ₽** | **34%** |
| Pay-as-you-go (карточка) | 5 ₽ | ~1.2 ₽ | **+3.8 ₽** | **76%** |

**Pro тариф теперь рентабельный без подъёма цен.** Можно даже снизить цены для агрессивного маркетинга и всё равно зарабатывать.

## Дополнительная оптимизация в Tier 2 (1 неделя работы)

После реализации базовой замены провайдеров доступны:

1. **Anthropic prompt caching** — для premium-эскалации на Claude: -90% на cached input. Применимо к системным промптам + JSON schema (~3000 tokens которые одинаковы для всех товаров).

2. **Redis SKU-level cache** — популярные товары (iPhone, AirPods, Nike) обрабатываются один раз, переиспользуются на тысячах листингов. TTL для статичных attrs — 90 дней. **-70-90% обращений на повторных запросах.**

3. **Cascade routing** — cheap-first классификатор определяет «простой ли товар», 70% → cheap stack, 30% → premium. **-75% от premium model cost.**

После Tier 2: $0.012/товар → $0.006-0.008/товар (-50%).

## Что мониторить в работе

В каждом запросе сохранять в `audit_trail`:
- `total_llm_calls` — сколько обращений сделано
- `total_cost_usd` — фактическая стоимость в долларах
- `provider_breakdown` — сколько использовано каждого провайдера (DeepSeek, Gemini, Claude, Serper)
- `stage_breakdown` — где сколько обращений
- `cache_hits` — сколько ответов из cache (бесплатно)
- `escalations_to_premium` — сколько раз эскалировали в premium стек
- `early_exit_stage` — на каком этапе остановились

Эти данные позволят:
- Реальные данные для оптимизации тарифов
- Видеть где основные траты
- Балансировать routing thresholds
- Демонстрировать клиентам прозрачность billing
