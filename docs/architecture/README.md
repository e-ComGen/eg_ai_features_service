# Документация архитектуры

Здесь лежат схемы и описания того, как устроен микросервис cpAiFeatures — что он делает, какие данные где ходят и сколько это стоит.

## Чем рисуем схемы

**Mermaid** — основной инструмент. Это текстовый формат, который GitHub превращает в картинку прямо при открытии `.md` файла. То есть зашёл на репозиторий, открыл документ — увидел диаграмму. Ничего дополнительного ставить не надо.

Если нужно отредактировать или скачать картинкой:
- [mermaid.live](https://mermaid.live) — вставил код, увидел превью, скачал PNG/SVG или экспортнул в draw.io
- В VSCode плагин `Markdown Preview Mermaid Support` — рисует прямо в редакторе
- В PyCharm плагин `Mermaid` — то же самое

**draw.io / diagrams.net** — если Mermaid не хватает для сложных схем. Тогда я сгенерю файл `.drawio`, ты откроешь его в [app.diagrams.net](https://app.diagrams.net) (или установишь desktop-версию) и сможешь редактировать визуально.

## Правила обновления

- Если меняем архитектуру — сначала обновляем эти документы, потом пишем код. Не наоборот
- Одна схема = один уровень понимания. Не мешаем классы и поток данных на одной картинке
- Подписываем блоки понятно: название этапа + «(1 обращение к ИИ)» если применимо
- Цветовая разметка (для общей навигации по схемам):
  - 🔵 синий — то что уже работает и не трогаем
  - 🟢 зелёный — дёшево, без обращений к ИИ
  - 🟡 жёлтый — точка принятия решения (развилка)
  - 🟣 фиолетовый — про фото / vision
  - 🔴 красный — дорогое (web search, полный pipeline)
